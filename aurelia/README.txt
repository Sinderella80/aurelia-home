Aurelia Home - luxury furniture store
1) Quick preview (no server): open index.html. Login works locally (browser storage).
2) With database login: copy the folder to C:\xampp\htdocs\aurelia, start Apache + MySQL in XAMPP,
   open http://localhost/phpmyadmin, import database.sql, then visit http://localhost/aurelia/index.html
Files: index.html, shopping.html, about.html, contact.html, Style.css, java.js, php/, database.sql
